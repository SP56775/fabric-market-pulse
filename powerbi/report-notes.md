# Power BI Report Structure

## Page 1: Historical Price Analysis
- Symbol slicer, date slicer
- Cards: Latest Close, High, Low, Change %
- Line chart: price trend
- Table: detailed OHLC (top 100, sorted desc, conditional color on Close)

## Page 2: Volume Analysis
- Cards: Total/Avg Volume
- Column chart: volume over time
- Table: top volume spikes
- Matrix: volume heatmap by hour
- Line chart: volume ratio vs baseline
- Scatter: volume vs price change correlation
